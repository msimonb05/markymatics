## How to Run Locally

| Command | Action |
| :--- | :--- |
| `bun install` | Install dependencies |
| `bun run dev` | Start the dev server at `localhost:4321` |
| `bun run build` | Build the site to `./dist/` |
| `bun run preview` | Preview the build locally |
